# Kurfanova Muzik - Android Mobile App

Kurfanova Muzik (https://kurfanova.kurfa.workers.dev) icin resmi, canli guncellenen Android mobil uygulamasidir.

## Ozellikler
- **Canli Senkronizasyon**: Web sitesinde veya Cloudflare uzerinde yapilan her degisiklik uygulamaya aninda yansir, tekrar APK yukleme gerektirmez.
- **Arka Planda Calma**: Telefon ekrani kapandiginda veya diger uygulamalara gecildiginde ses kesilmez.
- **Donanim Hizlandirmasi**: 60/120 FPS akici arayuz, sifir tarayici fazlaligi.
- **MediaSession Entegrasyonu**: Kilit ekrani ve bildirim cubugu uzerinden tam muzik kontrolu.
